# 工作台 2：统一拼装与投影视角（2026-11-05）

场景：Assets/Dollwright/ArtTests/Workbench_2_0/RetrievalDemo/Scenes/Workbench_2_0_RetrievalDemo.unity

按 Play 后点击操作台，或点击“开始组装”。

- 人偶浮在操作台上，使用接近平视的统一镜头。右侧线索板展示当前卡口图样和实时青蓝色半透明剪影；无需切换俯视检查界面。
- 图样和剪影按相同固定比例呈现。前后移动部件不改变投影倍率；重叠部件的剪影透明度保持一致。图样不显示尺寸或自动匹配评分。
- Tab / “下一张图样”切换两个卡口。出发时将当前正面投影方向对应到实际卡口平面。
- 左键从仓库格子直接拖出部件，也可拖动已安装部件。格子使用真实 3D 模型预览。
- 拖回仓库 / Delete 归还并重置；重新拿出不会保留旧角度。“重置选中部件”恢复该部件待装姿态。
- 右键在部件上拖动翻转；在外围细圆环上绕圈拖动可平面旋转。滚轮上下翻，Shift＋滚轮平转。
- “单件 / 整体”切换旋转对象，Ctrl 临时整体旋转。整体旋转保留所有拼装关系；单件模式下可选中躯干单独旋转，旋转后须检查连接状态。
- 小范围自动吸附保留，阻止明显埋入躯干或部件重叠。已连接部件旋转时尽量保持接触侧。
- 右侧只有文字、勾号与删除线的三条任务清单：一个头部、至少一条手臂、一种前进方式。有效连接后打勾并划掉；前进方式为两条腿或一个滚轮。三项满足后才显示“进入关卡”，拆下/断开后撤销相应勾选并隐藏入口。所有选用件仍须有效连接，拖动中或存在额外无效部件时不可出发。
- 展示架移到原线索板所在的左侧位置；当前图样板保持在右侧。
- 通道自动慢速前进，Q/E、R/F 调整朝向。两个卡口间隔保持 6 个单位。失败返回保留本次组装。
- 终点使用 A/D 调整伸缩、Q/E 调整手臂角度，空格抓取；普通短臂够不到深处目标。
- 当前原型退出 Play 后重置，无永久存档。

仅修改原有运行与编辑器脚本，未新增重复场景或美术资产。布局在运行时布置，原始工作台美术场景不受影响。

验证：统一视角、整体与躯干旋转、仓库拖放/归还、吸附/重置、两种移动部件组合通过卡口、伸缩臂取物和失败保留已通过运行检查。截图为 Unity 实际运行画面。真实操作手感仍需试玩反馈。
