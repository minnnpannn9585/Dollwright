# 主菜单与存档

打开 `Assets/Dollwright/Graybox/Scenes/MainMenu.unity`，点击 Play。
构建列表首场景也已设为 MainMenu。

- 新游戏：覆盖当前存档，清空成品人偶、其他材料、制作草稿及上次梦境记录。只保留棉花素胚 R1 ×1、笑脸手绘 F01 ×1。
- 进入工作台后，点击中央圆形制作台，点击“制作”。第一只基础人偶制作完成后，小床入梦按钮才启用。
- 继续：读取已有存档中的人偶、材料与制作草稿，返回工作台。没有有效存档时按钮不可用。梦境中途的位置和箱子状态不在跨启动存档范围内，Z 回溯仍是单次梦境内的检查点功能。
- 设置：只有占位说明和返回按钮，没有虚构的设置项。
- 工作台左上角“主菜单”可以返回入口。制作、材料入库、草稿选择沿用自动保存。

工作台背景图片、专属背景材质已经移除，使用纯色相机背景；桌面模型、材质和灯光保持现状。

存档仍使用原文件 `Application.persistentDataPath/dollwright-customization-v1.json`，兼容现有版本 1 存档。
新游戏会同时刷新主存档及备份，避免损坏恢复时带回上一轮的人偶。
测试全部使用临时目录，不修改玩家真实存档。
