# Z 检查点回溯

每个有 GrayboxRun 的可玩灰盒场景自动接入，包括 MovementTest、Dream01，以及 Dream02 的方箱入口和连续主关卡。工作台是选择界面，没有推箱回溯。

按 Z 或点击右下角“回溯检查点”。迷雾从屏幕四周收拢至全屏，完全遮住后恢复玩家与所有箱子，再散开。过场期间暂停玩家和箱子的物理模拟与操作，连续按 Z 不会叠加过场。

进入场景时保存初始快照。进入 Checkpoint 触发区后更新快照：保存触发器指定的玩家出生点与当时所有箱子的位置。Dream02 连续主关卡在舞台地面、电锯区入口和双箱区入口设有检查点，快照覆盖整个场景的 5 个箱子。箱子若正在掉落，快照使用其安全出生位置。Z 恢复最近快照，不是单步撤销，也不会跨回上一个场景。

恢复时：

- 所有箱子同时回到快照位置；清除掉落、速度和旋转状态，恢复水平推箱轨道。
- 玩家回到检查点指定位置；清除速度、跳跃缓存、穿墙状态，防止卡在屏障内。
- 压板、电锯根据恢复后的玩家和箱子位置重新计算；镜头在遮满时同步到出生点。
- 已收材料与已探索视野保留；不会重复计数。

普通掉落仍沿用原关卡的复活处理。Z可用于主动恢复整组箱子布局；新增锯架接触则自动执行该回溯。

检查点只保留在当前 Play 会话内，不是磁盘保存。退出 Play 后清空。

调整入口位置：编辑 GrayboxRun.initialSpawn。添加途中检查点：新增带 Trigger Collider2D 的 GrayboxTrigger，Action=Checkpoint，Checkpoint 为安全的玩家中心坐标（地面顶部 + 约0.76）。检查点应设在谜题开始前、稳定实体平台上，避免把已卡死的箱子布局保存成检查点。

GrayboxRewind 的关闭/保持/展开时长默认0.45/0.12/0.55秒。组件由 GrayboxRun 在运行时自动添加，可在 Inspector 预先添加以保存自定义时长。
