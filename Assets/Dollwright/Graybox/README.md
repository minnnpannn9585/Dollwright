# Dollwright · 快乐梦境灰盒 v01

Unity 2022.3.62f3c1，2D URP。这个目录包含新增的测试资产；已有的 `Assets/Scenes/Dream01.unity` 和 `SampleScene.unity` 保持原样。

## 打开和操作

1. 等待 Unity 完成编译。
2. 菜单 **Dollwright → Graybox → Open Movement Test** 打开移动测试，或 **Open Dream 01** 打开第一段路线。
3. 点击顶部 ▶ Play，点一下 Game 画面，让键盘输入进入游戏。
4. A/D 或左右方向键行走，空格跳跃。长按空格跳得更高，轻点为短跳。R 重新开始本场景。
5. 退出 Play 后再调整参数；Play 时的 Inspector 改动不会保存。

## 已实现的第一段

游乐园入口 → 前庭台阶 → 马戏团 → 大魔术箱顶取得 H1 → 三段游乐园跳跃 → 泡泡摊 → 醒来出口。

- 快乐人偶仅行走、跳跃；前庭箱子可通过行走推动，是候选交互。
- 魔术箱对快乐人偶保持实体碰撞，可登顶，不能进入。
- B1/B2/B3 为三个素胚；F1/F2 为两种面孔；H1 为魔术师头部。B3 被泡泡摊遮挡，靠近后遮挡淡出。
- 已探索区域保持显露，右侧视野随前进逐步打开。
- 掉落回最近检查点，材料保留；R 会清空本次记录并重开。
- 出口要求取得 H1；普通材料可遗漏，便于测试收集引导是否有效。
- HUD 只用于灰盒反馈，不代表最终 UI。没有倒计时、战斗、经营或人偶制作系统的新增实现。
- 完成后显示“醒来”，不跳转工作台；第二段、制作界面和正式美术暂未实现。

## 适合调整的参数

选择 `Player_WhiteHappinessDoll` 调整 `GrayboxPlayer2D` 的速度与跳跃速度；Rigidbody2D 的 Gravity Scale 决定重力。

当前速度 4.2、跳跃初速度 11.5、重力倍率 2.8。理想完整跳跃约高 2.41 单位、水平跨越 3.52 单位；实际碰撞与短跳需要试玩判断。三处地面缺口为 3、3、2.5 单位。

选择 `MainCamera_StraightSideView` 调整镜头大小、横向前视距离与跟随速度。选择 `07_Fog_RevealAhead` 调整视野前方显露距离，确保跳跃落点能提前看到。

空间尺寸为初稿。约一分钟是体验目标，首次试玩时间尚未验证。建议先记录能否看懂箱顶路线、漏掉哪些材料、短跳是否易误操作，再决定缩放关卡和速度。

## 自动检查和连接

PlayMode 测试检查移动、跳跃、台阶、魔术箱、缺口、拾取、出口、复活和视野。测试结果写入 `Logs/DollwrightGraybox`，实际通关会写入 `playtest-*.json`，记录用时、跳跃数、掉落数和材料。

编辑器加载本项目后会在 `Logs/DollwrightGraybox/Bridge/state.json` 写本地状态，便于 Codex 检查项目与 Play 状态。连接只使用本地文件，不安装第三方插件，不建立网络服务。允许的操作为查看状态、打开两张灰盒场景、Play/Stop/Pause/Resume 与 Game 截图。场景有未保存修改时拒绝切换。

菜单 **Build Both Test Scenes** 会重新生成这两张灰盒场景，因此手动调整场景后，应先另存版本再重新生成。
