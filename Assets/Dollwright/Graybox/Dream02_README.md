# Dream 02 — 两场景连续关卡
更新：2026-10-20

## 两个可玩场景
1. Scenes/Dream02_MagicBox.unity：保留原先的方箱入口。出生在箱顶，按 E 落入，再穿右侧屏障进入主关卡。
2. Scenes/Dream02_MagicStage.unity：魔术舞台 → 电锯消失术 → 双箱替身 → H2 材料 → 醒来出口。

主关卡全程共用一个玩家、GrayboxRun、镜头和迷雾。区域接缝可以直接走过；材料、箱子和机关状态在同一场景持续保留。
Build Settings 和 Scenes 目录中，Dream02 只保留以上两个场景。

## 打开与操作
- 工作台：制作魔术师人偶后，点击小床，再点击展示架上的成品，进入方箱入口。
- Unity 菜单 Dollwright > Graybox > Open Dream 02 - Magic Box 打开入口。
- Open Dream 02 - Magic Stage 打开连续主关卡。
- Open Dream 02 - Saw section / Double crate section 打开同一个主关卡，并在 Scene 视图聚焦对应区域。

A/D / 方向键移动；空格跳跃（长按较高）；E 穿越黄色屏障 / 在门前醒来；Z 恢复最近检查点；R 重开整个当前场景；T 返回工作台。

## 区域层级与坐标
| 层级对象 | 区域原点（世界坐标） | 内容 |
|---|---|---|
| Section_01_MagicStage | (0, 0) | 原魔术舞台、A 点推箱、R1 和 F1 |
| Section_02_Saw | (35, 6.6) | 单箱、P1、第一台电锯、R2 |
| Section_03_DoubleCrate | (58, 6.6) | 双箱、P2、C 点、第二台电锯、H2 与醒来门 |

两处接缝分别位于世界 x=32 和 x=55，地面顶高均为 6.6。
原魔术舞台内的平台位置保留；后两区按整体平移接入，内部谜题的相对位置和高度保留。
连续镜头沿 x 约 -4～91 跟随，攀爬时继续纵向跟随。

## 谜题
魔术舞台：由左上入口落到地面 → 箱子被帷幕挡住 → 跳上低顶平台、穿到后台 → 从右侧将箱子推回 A 点 → 踩箱登高 → 取得 R1、F1 → 向右走入电锯区。

电锯区：将箱 A 留在 P1 → 电锯抬起 → 人偶穿帷幕后通过锯架 → 取得 R2 → 继续向右进入双箱区。

双箱区：箱 A 留在 P2 维持电锯抬起；箱 B 先推到帷幕边，经低顶平台穿到后台，从右侧将 B 推回 C 点。踩 B 登上上层通道，穿帷幕通过锯架，取得 H2，再到门前按 E 醒来。

蓝色边界和灰色平台保持实体；箱子不能穿帷幕；电锯不能被穿越。穿墙持续 1.3 秒，墙内结束时等待角色离墙再恢复碰撞。

## 检查点与视野
主关卡保留原舞台地面检查点，增加电锯区和双箱区入口检查点。
每次记录玩家的安全位置及当前全部 5 个箱子的位置。进入后段后回溯，会保留之前已经摆好的箱子状态，并重新计算两个压板和电锯。
Z 过场仍为迷雾收拢至全屏 → 恢复 → 散开；已收材料和已探索视野保留。
视野随区域采用原先的前方显露距离，只有一套持续扩展的探索记录。
所有材料只在最终醒来后入库，不在区域接缝处重复结算。

## 编辑
优先在各区域层级下移动具体平台、障碍或箱子。箱子的 Min X / Max X 是世界坐标；检查点坐标和启用 world-space 的 PlateToSaw 连线也使用世界坐标。
若整体移动区域，应同步这些世界坐标参数。现有合并已完成同步。
Dream02ContinuousLayout 保存区域引用，负责跟随玩家位置切换原有区域标题与视野距离。
