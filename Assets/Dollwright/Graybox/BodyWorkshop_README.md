# 素胚加工玩法示例

普通流程：点击工作台中央制作台 → 选择棉花/木头/陶瓷 → 确认素胚 → 完成加工 → 完成素胚 → 选择脸部和头饰 → 制作。
脸部和头饰仍是点击即预览，不追加小游戏。切换材质需要重新加工，同材质的脸部/头饰变化不重置加工结果。

## 三个极简示例
- 布偶：←/→ 转动布料，按住空格送布缝纫，松开暂停。针头固定，沿浅色引导线缝完一圈。明显偏离时暂停前进并回到最近正确缝合位置，调整方向后继续。
- 木偶：左键按住木料左右边缘拖动，逐层去料。浅色线是目标，绿色表示该段已接近图样，削过头会显示橙色，可重做。先做固定正面轮廓，不是任意三维雕刻。
- 陶偶：按住空格转盘转动，同时用左键在泥胚边缘向内/向外拖动，改变这一高度及邻近区域的宽度。松开空格不会塑形。目标是旋转对称躯干。

没有倒计时、评分和失败扣料。进度条只提示完成程度。加工中返回/重做不写入库存；最终“制作”沿用原有原子存档扣料流程。
每做一个新的人偶都需要加工一次。加工进度暂不跨退出游戏保存。历史成品人偶不受影响。

## 快速体验三种材质
Unity 顶部菜单：Dollwright → Graybox → Preview body workshops (temporary materials)。
会进入带有临时材料的工作台制作界面，三种素材都可测试。停止 Play 即结束预览，临时材料和人偶不会写入真实存档。
普通新游戏仍然只有 R1 ×1、F01 ×1，不额外赠送木头或陶瓷。

## 美术与范围
本轮是由色块、三角形、轮廓线组成的交互原型。缝纫机、刀、手和转盘均为简化示意。
加工中形状会实际响应操作；完成后使用已有标准素胚模型，不把手工轮廓写回最终人偶的网格。头和四肢沿用原有占位资产。
加工模型、界面和几何绘制分别由 BodyWorkshopSession、BodyWorkshopUI、BodyWorkshopGraphic 管理，后续可替换为正式 3D 表现。
